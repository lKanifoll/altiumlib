5. Тестируем соединение
![[Pasted image 20240628115328.png]]

6. Закрываем все окна кнопками ОК
7. Скачиваем [репозиторий](https://github.com/lKanifoll/altiumlib.git) с файлами компонентов в удобное место или по стандартному пути хранения библиотек альтиума:
```
C:\Users\Public\Documents\Altium\AD22\Library
```

8. Открываем файл altiumlib.Dblib  и проверяем коннект
![[Pasted image 20240628150413.png]]

9. Если коннект есть, значит все сделано правильно. Файл altiumlib.Dblib уже предварительно настроен на работу с библиотекой из репозитория. Осталось добавить в библиотеку для использования непосредственно в проектах.
   Для установки жмем install на вкладке Components:
   ![[Pasted image 20240703090921.png]]
   
   или, если у вас уже установлены какие либо библиотеки:
   ![[Pasted image 20240703091104.png]]

   Далее, нажимаем кнопку install и выбираем наш файл altiumlib.Dblib
   На вкладке Components должны появиться библиотеки:
   ![[Pasted image 20240703091411.png]]
   Первая синхронизирует базу с компонентами по MFPN, вторая - по ID.
   Если все сделано правильно, то отобразится список компонентов, щелкнув по одному из них должны быть видны его Symbol и Footprint:
   ![[Pasted image 20240703093016.png]]
   
10. Далее, для удобства использования библиотеки нужно сгруппировать поля компонентов. Добавить или убрать видимые поля можно в Select Columns. Нажимаем правой кнопкой на любое обозначение поля и включаем группировку полей:
![[Pasted image 20240703091943.png]]
